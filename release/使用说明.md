# 记分板 App（离线版）使用说明

版本：2.0.0（versionCode 2）
包名：com.jfbg.scoreboard
文件：`记分板-v2.0.0-离线版.apk`（583,481 字节）

---

## 一、安装

APK 已放在手机存储里，两个位置任选：

- `/sdcard/Download/记分板-v2.0.0-离线版.apk`
- `Android/data/app.dsh.mobile/files/scoreboard2.apk`

**步骤**：打开手机「文件管理」→ 下载 文件夹 → 找到 `记分板-v2.0.0-离线版.apk` → 点击 → 允许「安装未知应用」→ 安装。

因为和旧版**同包名、同签名**，会**直接覆盖升级**，不需要先卸载。

> 如果系统提示「签名不一致」或「应用未安装」，说明手机上那个不是 v1.0.0，需要先卸载再装。

---

## 二、第一次打开

App 首次启动会把内置的初始数据（12 名成员、242 条记录）写入手机本地数据库，之后所有改动都保存在本机，**完全不需要网络**。

- 断网、飞行模式、没插卡的手机都能正常用
- 换手机不会自动同步数据（没有服务器了），要用「导出 / 恢复备份」搬家

---

## 三、功能说明

| 页面 | 能做什么 |
|---|---|
| 🏠 统计 | 看总分排名、每人当前分数 |
| ⚡ 管理 | 加减分（打分值 + 选分类 + 填原因）、批量调整、添加成员、删除成员、改管理员密码 |
| 📋 详细 | 点某个成员看他的全部记录；按日期筛选；撤销 / 编辑某条记录 |
| 🎲 抽签 | 转盘随机选人、分组抽签 |

**加减分流程**：管理页 → 点成员姓名 → 选分值（或自己填）→ 选分类 → 可填原因 → 确认。改完左上角会显示「已保存」。

**删除记录**：详细页里每条记录右侧有撤销按钮。这是**软删除**，记录标记为已删除并从总分里扣掉，但数据仍在（导出「全部数据」时能看到），别人查不出你删过。

**改密码**：默认管理员密码 `admin2024`。管理页里有「修改密码」，改完只存在这台手机上。**忘了密码没法找回**（没有服务器），只能卸载重装回到初始数据 —— 所以建议先导出备份。

---

## 四、导出 Excel

三个导出按钮都在「管理」页底部：

- 导出成员总分 → `记分板_成员总分_<时间>.xlsx`
- 导出全部数据 → `记分板_全部数据_<时间>.xlsx`
- 导出某人明细 → `<姓名>_详细记录_<时间>.xlsx`（在「详细」页）

文件保存到：**内部存储 / Download / 记分板导出 /**

用手机自带的「文件管理」→ 下载 → 记分板导出 就能找到，也可以用 WPS / 微信发出去。

---

## 五、备份与恢复

- **备份**：管理页 → 备份数据 → 会生成一个 JSON 文件保存到手机。建议每周备一次。
- **恢复**：管理页 → 恢复备份 → 选那个 JSON 文件 → 确认。**会覆盖当前全部数据**。

备份文件包含所有成员、所有记录（含已删除的），换手机时把它拷过去恢复即可。

## 六、和网页版的关系

**这两个现在是完全独立的两套东西：**

| | 网页版 jfbgv1.cn | 这个 App |
|---|---|---|
| 数据存哪 | Supabase 云端 | 手机本地 SQLite |
| 要不要网 | 要 | 不要 |
| 谁能看见 | 多台设备共享同一份 | 只有这台手机 |

也就是说：**App 里加分，网页上看不到；网页上改，App 也不知道。** 两边各记各的。

App 的初始数据是网页版在导出那一刻的快照（12 人 / 242 条记录，最高分张至恒 465）。之后网页上的新变动不在 App 里。

如果以后想让两边重新同步，需要另外做联网改造。

## 七、更新 App

改了原生代码（界面、权限、数据库结构）才需要重装：

```bash
cd scoreboard-app
# 先改 android/AndroidManifest.xml 里的 versionCode 和 versionName
bash build.sh
```

产物在 `build/记分板-v<版本>-离线版.apk`，覆盖安装即可，**本地数据不会丢**（数据库升级走 onUpgrade，代码里明确不清库）。

只改网页部分（`android/assets/www/index.html`）也要重新 build.sh，因为页面是打包进 APK 的。

## 八、已知问题

1. **转盘发虚**：高分屏（dpr 2.5）下抽签转盘边缘略模糊，原因是 canvas 固定 200×200 没做像素比适配。不影响功能。
2. **密码无防爆破**：错误密码可以无限次尝试，没有延迟或锁定。这是单机 App，风险仅在手机被别人拿到时。
3. **多端并发**：只有一个设备能用，不存在并发覆盖问题（这是本地化的好处）。
4. **记录 id**：早期从 Supabase 导出的数据里，记录 id 是浮点数且有 2 组重复，已在打包前修掉（加了 `_2` 后缀），否则初始化会丢 2 条记录。现在新建记录用 `crypto.randomUUID()`，不会再撞。
